# Mahadev Book — HTML/CSS/JS Demo

A responsive, single-page front-end recreated from the supplied visual reference.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive dark navy/gold visual system
- `script.js` — navigation, demo modal, match rendering and refresh interaction

## Run
Open `index.html` directly in a browser.

## Notes
- No framework or build step is required.
- The sports interface is intentionally a front-end demonstration.
- No real-money payment, betting, wallet or authentication backend is implemented.
- Google Fonts are loaded from the web; the rest of the UI is self-contained.

## WhatsApp CTA
- Floating **Get Started** button opens WhatsApp for `9999999999` with the prefilled message `Hi`.

- Mobile viewport safeguards prevent oversized content from triggering an initially magnified layout.
